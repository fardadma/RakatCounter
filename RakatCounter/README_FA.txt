رکعت‌شمار هوشمند نماز - پروژه اندروید

این پروژه با Kotlin و Jetpack Compose آماده شده است.

ساخت APK:
1) Android Studio را نصب کنید.
2) پوشه RakatCounter را از مسیر File > Open باز کنید.
3) منتظر بمانید Gradle Sync کامل شود و در صورت درخواست، Android SDK 35 را نصب کنید.
4) از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کنید.
5) فایل خروجی معمولاً در مسیر app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

حداقل نسخه اندروید: Android 8.0 (API 26)
مجوز لرزش در Manifest تعریف شده است. سنسور مجاورت اختیاری است؛ روی گوشی فاقد این سنسور شمارش خودکار کار نخواهد کرد.

توجه: این محیط فاقد Android SDK و Gradle است؛ APK در اینجا ساخته یا روی دستگاه آزمایش نشده است. پروژه برای باز شدن و ساخت در Android Studio آماده شده است.
